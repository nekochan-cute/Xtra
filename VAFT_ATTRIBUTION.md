# VAFT attribution

The automated fallback-player-type sequence and stitched-ad marker checks in
`VaftPolicy` are adapted conceptually from the VAFT algorithm in
[pixeltris/TwitchAdSolutions](https://github.com/pixeltris/TwitchAdSolutions/tree/master/vaft).

This is a native Android implementation using the existing Xtra playback
services, not the original Twitch JavaScript userscript. The upstream project
was archived in March 2026 and Twitch may change its ad-delivery behavior.
